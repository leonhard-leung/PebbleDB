## [0.1.0]
### Added
* Interactive CLI
* Database management
  * Create databases
  * Drop databases
  * List databases
  * Select and deselect databases
* Table management
  * Create tables
  * Drop tables
  * List tables
  * Describe tables
* Record management
  * Add records
  * select records
  * update records
  * delete records
* Persistent binary `.peb` database storage
* Local HTTP server
* REST API for database, table, and record operations
* CLI help page
* Server management commands
  * Start server
  * Stop server
  * Show server status
* Application data storage under the user's local application data directory
* Initial release documentation
